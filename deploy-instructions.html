🚀 Deploy Your Wedding Website

Follow these simple steps to make your website live!

1

Go to GitHub

Open https://github.com/new in your browser

📝 Note: If you don't have a GitHub account, create one first at github.com (it's free!)
2

Create New Repository

Fill in the details:

  1. Repository name: wedding-invitation or aliya-kyz-uzatuu
  2. Description: "Aliya's Wedding Invitation - Kyz Uzatuu 2026"
  3. Visibility: Choose Public (required for free GitHub Pages)
  4. DO NOT check "Initialize repository" or add README/gitignore
  5. Click "Create repository"
3

Connect Your Local Repository

After creating the repository, GitHub will show you some commands. COPY THIS EXACT COMMAND from GitHub (it will have your username):

⚠️ IMPORTANT: Replace YOUR_USERNAME below with your actual GitHub username!
git remote add origin https://github.com/YOUR_USERNAME/wedding-invitation.git git branch -M main git push -u origin main

Or if you see an SSH URL on GitHub, use:

git remote add origin git@github.com:YOUR_USERNAME/wedding-invitation.git git branch -M main git push -u origin main

Run these commands in your Terminal (one at a time or all together)

4

Enable GitHub Pages

  1. Go to your repository on GitHub
  2. Click "Settings" tab (top menu)
  3. Click "Pages" in the left sidebar
  4. Under "Source", select:
    • Branch: main
    • Folder: / (root)
  5. Click "Save"
✅ Success! GitHub will show a message like:
"Your site is ready to be published at https://YOUR_USERNAME.github.io/wedding-invitation/"
⏰ Wait 1-2 minutes for GitHub to build and deploy your site
5

Get Your Live URL

Your wedding invitation will be live at:

https://YOUR_USERNAME.github.io/wedding-invitation/

Replace YOUR_USERNAME with your actual GitHub username

📱 Example URLs:
• If username is "nuraaly": https://nuraaly.github.io/wedding-invitation/
• If username is "johndoe": https://johndoe.github.io/wedding-invitation/
🎉

Your Wedding Website is LIVE!

Share this URL with your guests:

https://YOUR_USERNAME.github.io/wedding-invitation/
